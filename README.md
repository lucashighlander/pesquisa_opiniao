## 📘 Sobre o projeto

Projeto desenvolvido em **Python** como atividade prática de Lógica de Programação do curso Técnico em Desenvolvimento de Sistemas.

A atividade tem como foco o uso de **estruturas de repetição** e **estruturas de decisão**.

Como situação-problema, foi proposta uma pesquisa de opinião para a empresa fictícia **TudoWeb**, com o objetivo de registrar a avaliação dos clientes sobre o atendimento.

## 🔁 Conteúdos utilizados

Nesta atividade foram utilizados:

- estrutura de repetição `for`;
- estrutura de repetição `while`;
- estruturas de decisão `if` e `elif`;
- variáveis;
- entrada e saída de dados;
- contadores;
- validação de respostas.

## ⚙️ Funcionamento

Para cada entrevistado, o programa solicita:

- nome;
- idade;
- opinião sobre o atendimento.

As opções são:

- `1` → Excelente
- `2` → Bom
- `3` → Ruim

O programa valida a resposta informada e, ao final, exibe:

- quantidade de respostas **Excelente**;
- quantidade de respostas **Ruim**.

A pesquisa final é realizada com **50 entrevistados**.

## ✅ Testes

Foram realizados testes com **10 entrevistados** para validar o funcionamento do programa, conforme solicitado na atividade.
